Use the code provided in the file matrix2.data.zip as a basis for your program–the input / output
needed is already written for you. Matrices will be stored as a structure which we’ll typedef
as Matrix. This structure will contain the size of our matrix along with a statically-sized
two-dimensional array to store the entries.
typedef struct Matrix s {
size t R, C;
int *index;
} Matrix;
In this problem, the memory for each matrix will be dynamically allocated on the heap, and must be
freed at the end of the program. You will need to implement a function to allocate a matrix capable of
storing R
×
C elements, as well as a function that will destroy the memory for such a matrix.
Do not submit your solution to problem ‘matrix’ for this problem or use statically allocated mem­
ory; such solutions will not receive any points for the assignment, even though they would pass the
grader’s tests.
