
Question 1 (20 points): Classify each of the following as a violation of confidentiality, or
integrity, or availability and explain why/how:
1. Eve runs TCP SYN attack against Alice’s email server. This is a violation of activity
since a TCP SYN attack is a type of DoS attack that aims to disrupt the service by
flooding it with many TCP SYN requests which in this instance is the email server.
2. Eve is the system admin and misconfigures the company’s email server in a way that all
the received emails are broadcasted to all. This is a violation of confidentiality since
misconfiguring the email server in a way that all received emails are to all puts the
privacy of the emails at risk because it is the information is available to unintended
users.
3. Eve discloses Bob’s health records. This is a violation of confidentiality because
disclosing someone’s records without authorization is a breach of confidentiality.
Especially when it is personal and sensitive information like health records.
4. Eve overwrites the files under /var/log of a protected server with empty files. This is a
violation of integrity, the log files help track events and declare security issues, and
overwriting them with empty files will ruin the system’s reliability.
