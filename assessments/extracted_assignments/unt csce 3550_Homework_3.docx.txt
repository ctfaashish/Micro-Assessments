1. Why do we need Virtualization? State advantages & Disadvantages of Virtualization?
Virtualization allows multiple systems to run concurrently on the same hardware.
Virtualization helps manage systems more efficiently to save power, space, and cooling
costs, while working to meet the needs of the users.
Pros: hard efficient, available at all times, recover easy, quick setup, cloud migration
Cons: high initial cost, creates a security risk, and scalability issues.
2. List different type of virtualizations technologies and give one advantage and
disadvantage of each.
Full virtualization- Guest OS is isolated by the virtual machine from the virtualization
layer and hardware.
Pro: portable and compatible Cons: less secure and slow
Para virtualization- Guest OS isn’t completely isolated by the VM from the virtualization
layer and hardware, provides a different API which is utilized by the OS.
Pro: fast in operations Cons: less portable and compatible
OS-level virtualization- operating system create
multiple, isolated application environments that reference the same
kernel. Letting users perform different tasks on the same machine from different
applications.
Pros: offers near native performance Cons: No work offline
3. In a Virtualized environment what is the difference between host machine and Guest
machine?
In the host machine, it’s the default machine that has the guest OS installed to share
resources. The guest machine is installed in a virtual software which provides more than
one OS and allows multiple users compared to only 1 host user.
4. What is the purpose of the Guest Additions software? Where is it installed?
Guest additions software improves the guest’s performance and usability in virtualbox. It
is installed on the guest OS running the VM and allows features such as shared folders
to be used.

Containers standardize software packaging. They are a fusion of existing kernel
features, filesystem tricks, and networking hacks. It is managed by the container engine
that manages and pulls it all together. It is isolated to a private root filesystem and
process namespace.
6. Which Unix and Linux features does Containers rely on?
They rely on Kernel support (namespaces, control groups, capabilities, secure
computing), images (adds read/write layer that the container can update) and networking
(bridge mode and host mode).
7. What is the significance of UID 0? Who is allowed to use UID 0 and Why?
UID 0 is reserved for the root user. UID is used by the root user (superuser) to perform
any valid operation on any file or process.
