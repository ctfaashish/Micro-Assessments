To decrypt the PDF, you must install two tools: “John the Ripper” (a.k.a., “john”) and
“pdf2john” to guess the password. The john tool requires hashes as input, so first you

RECOMMENDED METHOD: Download and use the Parrot OS VM.

3. Open a terminal and navigate to the directory where you downloaded the PDF
4. Extract the hash from the PDF into a text file. Use pdf2john (which is in
/usr/share/john) to do this. Your command will look something like this:
/usr/share/john/pdf2john.pl Q6.pdf > myhash.txt
