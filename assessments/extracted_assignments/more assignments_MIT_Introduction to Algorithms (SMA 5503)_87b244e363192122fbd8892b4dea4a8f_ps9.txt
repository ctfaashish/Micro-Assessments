Problem 9-1. More parallel merge sort
In this problem we will improve the parallel merge-sort algorithm from lecture. The algorithm
2
described in class has work Θ(n lgn) and parallelism Θ(n/lg n). We shall develop an algorithm
with the same work, but higher parallelism.
(a) Given two sorted arrays containing a total of n elements, give an algorithm to find the
median of the n elements in Θ(lgn) time on one processor.
(b) Using the algorithm in part (a) as a subroutine, give a multithreaded algorithm to
2
merge two sorted arrays. Your algorithm should have Θ(n) work and Θ(n/lg n)
parallelism. Give and solve the recurrences for work and critical-path length, and
2
show that the parallelism is Θ(n/lg n), as required.
(c) Optional: Generalize the algorithm in part (a) to find an arbitrary order statistic. Using
this algorithm, describe a merge-sorting algorithm with Θ(n lgn) work that achieves
a parallelism of Θ(n/lgn).
