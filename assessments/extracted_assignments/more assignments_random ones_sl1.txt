1 Tape drives (4 pts.)
Consider a system with four processes and seven tape drives. The maximal needs of each process are declared
below:
Resource Declarations
Process A Process B Process C Process D
5 tape drives 5 tape drives 3 tape drives 2 tape drives
Imagine the system is in the state depicted below. List one request which the system should grant right
away, and one request which the system should react to by blocking the process making the request. Briefly
justify each of your answers.
Who Max Has Room
A 5 1 4
B 5 2 3
C 3 1 2
D 2 1 1
System 7 2 -
Solution
If D requests 1 tape drive, the request should be granted, as there is the following safe sequence:
1. D returns all 2 tape drives. The system now has 3.
2. C requests 2 tape drives, then returns all 3. The system now has 4.
3. B requests 3 tape drives, then returns all 5. The system now has 6.
4. A requests 4 tape drives, then returns all 5.
If A requests 2 tape drives, the system should block A. Otherwise, the system would have no more
resources, but every thread could request more resources. Therefore, there is no thread which could come
first in a safe sequence, so a safe sequence would not exist.

queue that is being ignored and will be garbage-collected—in other words, the item will be “lost.”
