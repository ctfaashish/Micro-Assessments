a. (10 Points) Write a stored procedure to display the number of distinct locations at
which the dog identified by DID was examined. DID is to be an input parameter
to the stored procedure. It is expected that your stored procedure will work for
any instances of the above schema. Demonstrate that the stored procedure works
by trying it on the above tables using each valid DID value.
b. (10 Points) Write a stored procedure to display the names and ids (vids) of the
veterinarians who have charged the highest fee. It is expected that your stored
procedure will work for any instances of the above schema. Demonstrate that the
stored procedure works by trying it on the above tables.
