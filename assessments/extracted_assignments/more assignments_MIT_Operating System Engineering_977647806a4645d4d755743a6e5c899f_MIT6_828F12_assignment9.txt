In-class: bigger files for xv6
In this assignment you'll increase the maximum size of an xv6 file. Currently xv6 files are limited to 140 sectors, or
71,680 bytes. This limit comes from the fact that an xv6 inode contains 12 "direct" block numbers and one "singly-
indirect" block number, which refers to a block that holds up to 128 more block numbers, for a total of 12+128=140.
You'll change the xv6 file system code to support a "doubly-indirect" block in each inode, containing 128 addresses of
singly-indirect blocks, each of which can contain up to 128 addresses of data blocks. The result will be that a file will
be able to consist of up to 16523 sectors (or about 8.5 megabytes).
