4. (8 points) In a typical office, biometric authentication might be used to control access to
employees and registered visitors only. We know the system will have some false
negatives, some employees falsely denied access, so we need a human override,
someone who can examine the employee and allow access in spite of the failed
authentication. Thus, we need a human guard at the door to handle problems as well as
the authentication device; without biometrics, we would have had just the guard.
Consequently, we have the same number of personnel with or without biometrics, plus
we have the added cost to acquire and maintain the biometrics system. Explain the
security advantage in this situation that justifies the extra expense.
- Having a biometric authentication system as an extra layer in addition to a guard can
greatly increase the level of protection there in the office. While the biometric
system can make some errors identifying employees (both false negative and
positive), the chances of that happening are still much smaller than a human.
5. (8 points) If you forget your password for a website and you click [Forgot my password],
sometimes the company sends you a new password by email, but sometimes it sends
you your old password by email. Compare these two cases in terms of vulnerability of
the website owner.
- Sending a new password to the user by email is less vulnerable than sending the user
their old password. The new passwords generated by the website are more likely to
be a random password, which encourages users to change them later, making it
more secure. Most people will keep using their old password when they are sent
their old one.

7. (12 points) Password Managers
a) What is a password manager and why is it useful?
- Password manager is a tool act as an encrypted vault that help user manage and
store their login credentials used to access accounts or services on the websites
or other devices, so user don’t have to remember them.. Most password
manager also comes with password generator that can help user to create strong
and unique passwords, which eliminates the chance of using the same password
across different systems.
b) What security risks are associated with password managers?
- Sensitive data are gathered in one place, making them an obvious target for hackers.
- Still relying on a master password to access the vault.
- Not all password managers have extra authentications.

your bank may shut down online access to your account after n failed login attempts).
