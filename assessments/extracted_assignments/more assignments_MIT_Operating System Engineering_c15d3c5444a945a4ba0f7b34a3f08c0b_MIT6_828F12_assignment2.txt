In-class: boot xv6
Boot xv6
Fetch the xv6 source:
$ mkdir 6.828
$ cd 6.828
$ git clone git://pdos.csail.mit.edu/xv6/xv6.git
Cloning into xv6...
...
$
Build xv6:
$ add -f 6.828
$ cd xv6
$ make
...
gcc -O -nostdinc -I. -c bootmain.c
gcc -nostdinc -I. -c bootasm.S
ld -m elf_i386 -N -e start -Ttext 0x7C00 -o bootblock.o bootasm.o bootmain.o
objdump -S bootblock.o > bootblock.asm
objcopy -S -O binary -j .text bootblock.o bootblock
...
$
If you are not using Athena for 6.828 JOS labs, but build on your own machine, see the instructions on the tools page.
If you have a build infrastructure on your own machine for lab 1, then you should be able to use that infrastructure for
building xv6 too.
