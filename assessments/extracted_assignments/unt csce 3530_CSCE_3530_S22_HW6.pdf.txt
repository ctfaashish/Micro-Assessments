1. Briefly explain TCP’s additive increase multiplicative decrease (AIMD) approach to
congestion. (4 Points)

sender to increase transmission rate to test for the amount of bandwidth
available until loss occurs. That process mentioned is called an additive
increase of the congestion window until congestion occurs where the window
size will then be decreased in half in a multiplicative manner.

7. Draw the router architecture. Label and describe all the blocks in the architecture.
(15 Points)
Router input ports: It performs the physical layer of line termination of an
incoming physical link at a router, also has data link layer which are cognizant
with ethernet. The lookup forwarding function is also performed at the input
port where the forwarding table is used to determine where a datagram that
when traveling through the switch fabric is forwarded to a specific output
port.
Router output ports: The output ports stores datagrams in a datagram buffer
and its scheduling discipline chooses among the queued datagrams for
transmission.
Router processor: The routing processor computes the forwarding table and
pushes them to the input ports and manages and executes routing protocols.
Switching Fabric: It enables a connection from the routers input port to the
output port. It is the network found inside a router, completely contained
within the physical router itself.

8. Describe the three different types of switching fabrics used in a router. Draw the
architecture for each type of switching fabric. (15 Points)
Memory Switch: The memory switch was a switching fabric commonly found
in first generation routers where routers were traditional computers with
switching under direct control of CPU. The packets were written into and read
from memory, but the speed of this process was limited as it only allowed 2
bus crossings per datagram/packet.
Bus: Switching via a bus is where datagrams from input port memory to
output port memory where the transfer is done directly via a shared bus.
However, the process is limited because the switching speed is limited by the
bus bandwidth.
Interconnection/Crossbar Network: Switching via a crossbar network was
able to overcome bus bandwidth limitations where its advanced design by
fragmenting
datagram into fixed length cells, switch cells through the fabric allowed
multiple packets to be forwarded in parallel.

9. Describe FIFO scheduling, Priority Scheduling, Round Robin (RR) Scheduling, and
Weighted Fair Queuing (WFQ) for incoming datagrams. (12 Points)

--- Page 8 ---
FIFO scheduling: Described as the First in First Out scheduling, where
packets that arrive in link are sent out in the order they arrive to the queue. It
also has a discard policy that if the queue/buffer is full, the router will discard
those packets, another policy where packets are dropped or removed based
on priority basis or randomly drop and remove packets.
Priority Scheduling: Scheduling where packets with the highest priority and
low priority are pushed to separate queues, and when they need to be sent
the packet with the highest priority is processed first.
Round Robin (RR) Scheduling: The Round Robin Scheduling is where
packets are classified into multiple classes where it cyclically scans class
queues and send one complete packet from each class if available. There is
no priority between packets.
Weighted Fair Queuing (WFQ): Weighted Fair Queuing is similar to the RR
scheduling as it also deals in classifiers and cyclically scans class queues.
The datagrams are sorted into a weighted queue, where each class gets a
weighted amount of service in each cycle.
10. List and describe at least five (5) fields in the IP datagram header. (10 Points)
Source IP address: Source of which datagrams are being sent; their unique
32-bit IP address is the source IP address.
Destination IP address: Unique field in which the datagrams being sent to
directed to this specific 32-bit address.
Version: It displays the current version of IP used, whether it be 4 or 6.
Identifier (16 bit): Gives packets a unique number that allows it to be used for
fragmentation and reassembly.
Time to Live: Number of hops a datagram can make before dropping, its “life”
decrements at each router it hops from.
