Lab 6a: Create Initial Baseline Using the Windows Forensic Toolchest

Scenario
Students will run Windows Forensic Toolchest against an existing system to create a baseline
that will be used for future analysis. WFT is a wrapper that takes incident response tools and runs
them and records the output.
An organization wants to be able to identify post compromise activity from the enterprise
standard gold builds. You are tasked with using the Windows Forensic Toolchest to create a
baseline on a system that is suspected to be compromised and compare it with a baseline that was
created on the same system at an earlier time. During the comparison look for any indicators
(IOC) that could be evidence of compromise.
Objective
 Create a baseline with the WFT (Windows Forensic Toolchest)
 Create a baseline of running services with the WFT
 Create a baseline of installed services with the WFT
 Create a baseline of key registries with the WFT
 Analyze the output of the created baseline

What other security tools can WFT run?
LA 6.3a
Answer List here…-cfg cfgfile
Uses cfgfile to determine which tools to run (defaults to ‘wft.cfg’)
-drive drive_letters
Specifies the drives to be used by wft (defaults to ‘C’)
-toolpath path_to_tools
Defines the path where wft tools are stored (defaults to ‘.\’)
-dst destination
Defines the path that reports will be written to (defaults to ‘.\’)
Note: Destination can include macros $magic$, $systemname$, $date$, or $time$
-shell cmdshell
Redefines shell references from cmd.exe to cmdshell
-noslow
Causes WFT not to run slow (S) executables in cfgfile
-nowrite
