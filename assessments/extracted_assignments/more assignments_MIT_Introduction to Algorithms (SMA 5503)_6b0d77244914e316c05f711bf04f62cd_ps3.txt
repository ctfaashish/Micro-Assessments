figure out where it came from. Skinner decides to see if some smart­alec MIT student can help
him out.
Skinner gives you a DVD containing the full text of the Springfield public library. The data is
stored in a binary string T[1],T[2],...,T[n], which we view as an array T[1 ..n], where each
T[i] is either 0 or 1. Skinner also gives you the quote from Bart Simpson’s book report, a shorter
binary string P[1 ..m], again where each P[i] is either 0 or 1, and where m < n. For a binary
